# QR Code Generator

A simple and responsive QR Code Generator built using **HTML, CSS, and JavaScript**. Generate QR codes instantly for any text or URL using the GoQR API.

## 🚀 Features

* Generate QR codes instantly
* Supports text, URLs, and GitHub profile links
* Responsive and clean user interface
* Smooth QR code appearance.

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* GoQR API

## 📂 Project Structure

```text
qr-code-generator/
│── index.html
│── style.css
│── app.js
└── README.md
```

## 📸 Preview

Enter any text or URL, click **Generate**, and the QR code will be created instantly. You can also download the generated QR code.

## 🔗 API Used

GoQR API

```
https://api.qrserver.com/v1/create-qr-code/
```

## 📌 Future Improvements

* QR code customization (colors and size)
